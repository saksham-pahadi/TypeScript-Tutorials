## 1.Initialize Project
``` npm init -y ```

## 2.Install TypeScript
``` npm i typescript ```

## 3.Initialize Compiler 
``` npx tsc --init ```
## 4.Create two Directories 
- dist
- src

## 5.Execute TypeScript Compiler
``` npx tsc ```
## 6.Execute TypeScript Code
``` npx tsx src/basic2.ts```


## Or Execute JavaScript Code
``` node dist/basic2.js ```
